### Student Grade Tracker

A Java application for managing student grades and generating performance reports.

## Features
- Add student grades
- Calculate average score
- Find highest score
- Find lowest score
- Generate performance reports

## Technologies Used
- Java
- Object-Oriented Programming

## How to Run

1. Compile:
   javac Student_Grade_Tracker.java

2. Run:
   java Student_Grade_Tracker
